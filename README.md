# BIG JOHN INTL Instagram 自動投稿

海外向けアカウント(@bigjohn.jeans_intl)用。週3回(月・水・金の朝8時台)、英語のリール(動画)またはカルーセル(写真)とキャプションが自動でできあがり、
スタッフが確認画面で「投稿する」を押すとInstagramに投稿される仕組みです。
BasShu用の仕組みをもとに、BIG JOHN INTL専用に作り直したものです。

- 投稿(動画の文字、キャプション、ハッシュタグ)は **英語**
- 確認画面、メール、管理シート、この手順書は **日本語**。確認画面にはキャプションの日本語訳が付く(投稿はされない)
- 読み手は北米が中心、アジア(香港・韓国・タイ)も。日本の午前に投稿すると、北米は前日の夜、アジアは朝

## リールとカルーセル(交互)

- 投稿ごとに **リール → カルーセル(写真だけの通常投稿)→ リール …** と交互に作る。柱の順番はそのまま回る
- 管理シート「設定」の「投稿の形式」で切り替え: `交互`(初期値)/ `リールのみ` / `カルーセルのみ`
- カルーセルは 着用写真 → 寄り → 商品 → 別カット の3〜5枚。4:5(1080×1350)に切り出し、文字は載せない
- フォルダの素材が動画のときは、カルーセルでは使わない(写真だけ)。AI生成の写真には札が付く
- お知らせは文字が要るので、必ずリールで作る(交互の順番は進めない)。見送りの作り直しは同じ形式で作る
- 写真が2枚に満たない商品は、リールに切り替える

## 中身

| 場所 | 役割 | 動く場所 |
| --- | --- | --- |
| `gas/` | 頭脳。商品の読み込み、商品・素材選び、文章づくり、確認画面、投稿、通知 | Google(Apps Script) |
| `src/` | 動画づくり。注文を受け取り、写真3枚・12秒の縦型動画を書き出す | GitHub(Actions) |
| `assets/` | BGM(6曲。投稿ごとに順番に使う)と、テスト用の仮画像 | |
| `docs/v/` | できた動画の置き場(GitHub Pagesで公開され、30日で自動的に消える) | |
| `test/` | Google側の代役を立てて全体を試すテスト | |

月額の費用は、文章づくりのAI利用料(ごくわずか。日本語訳のぶん、BasShuより少し増える)だけです。

## BasShu版との違い

- サイトは https://bigjohn-jeans.com(Shopify)。商品は色ごとに別の商品(約240件)
- 商品名「品番 (色番号) 名前 / 加工」を分解する。動画には名前を大きく、品番と加工を小さく出す。色番号は出さない
  - 例: `XX002 (001)『XXXX-EXTRA』MODEL SLIM STRAIGHT / ONE WASH` → `XXXX-EXTRA MODEL SLIM STRAIGHT`、`XX002 · ONE WASH`
- 直近と同じ分類(vendor)に加えて、**同じ品番(色違い)** も続かないように選ぶ
- 柱は「商品紹介 → 季節の着こなし → ヘリテージ → 色落ちと経年変化 → 商品紹介」
- 「ヘリテージ」シートに、サイト(About us)にある社史の事実を英語で7件入れてある。足すときも、サイトや資料にある事実だけ
- 「色落ちと経年変化」は、商品説明に書いてある範囲だけで書く。サイトの写真だけで作る(AI生成の画像は使わない)
- 止める表現(英語): 根拠のない最上級(best, finest, No.1, world-class, perfect など)、機能の言い切り(waterproof, antibacterial, UV, never fades など)、
  環境の言い切り(eco-friendly, sustainable, carbon neutral など)。AIに書かせず、投稿ボタンでも止める。「Japan's first」などの史実は、シートの事実にあるときだけ
- 季節の初期値: ショーツ・シャンブレー・リネンは春夏、ヘビーウェイト・フランネル・ウールなどは秋冬、ほかは通年(北半球の月で判定)
- 使用シーンの写真は「人が着ている写真」をAIが選ぶ。サイトの写真は2:3の縦長なので、9:16にしても左右が少し切れるだけ
- 文字は白、うしろに半透明の **ほぼ黒** の下地(ロゴの黒白に合わせた)。書体は欧文のサンセリフ(Inter)
- AI生成の画像の札は「AI-generated image」
- 最後の画面(商品名の上)と告知の画面に、ブランドのロゴ(`assets/logo_white.png`、白・透過)を置く。差し替えるときは同じ名前で入れ替える
- 「お知らせ」シートは英語で書く(動画にそのまま出るため)

## 設定の順番

1. GitHubに公開リポジトリ `bigjohn-intl-reel` を作り、この一式を入れ、Pages(`main` ブランチの `/docs`)を有効にする
2. Googleで Apps Script を作り、`gas/` の3ファイルを貼り付けて `setup` を実行する
3. ウェブアプリとして公開し(アクセスは「全員」)、URLと合言葉をGitHubの Secrets(`WEBAPP_URL`、`WEBAPP_KEY`)に入れる
4. スクリプト プロパティに `ANTHROPIC_API_KEY` を入れ、`testAI` を実行する
5. `suggestScenePhotos` を「残り0件」と出るまでくり返し実行する(約240件あるので数回かかる)
6. `makeNow` を実行して、最初の投稿候補を作る
7. Instagramをつなぎ(`IG_TOKEN`、`testInstagram`)、管理シートの「投稿曜日」に `月,水,金` を入れる(それまでは空のまま)

## 管理シートの「商品」でできること

| 列 | 使い方 |
| --- | --- |
| フォルダを作る | チェックすると、翌朝までにその商品の素材フォルダができる(すぐ作るなら `syncProducts` を実行) |
| 次に投稿する | チェックすると、次の回はその商品で作る。急ぐときは続けて `makeNow` を実行 |
| 季節 | 「春夏」「秋冬」「通年」。季節外の商品は選ばれない |
| 使用シーンの写真番号 | サイトの写真のうち、動画の1枚目に使う着用写真の番号。AIが入れた番号を直せる。0 は「なし」 |
| 寄りの写真番号 | 動画の2枚目に使う写真の番号 |
| 品番・色番号・色・種類 | 商品名から自動で取り出したもの(動画に出るのは品番と色・種類) |

## 素材のきまり

- フォルダが要るのは、力を入れたい商品だけ。1商品につき2〜3枚が目安
- 画像は JPEG か PNG(iPhoneの HEIC は対象外)。縦長(9:16)で入れる
- 動画は 30MB まで。使われるのは最初の約4秒。音は使わない
- 撮影した素材は、ファイル名を「実写」で始めると「AI-generated image」の札が付かない
- 色落ち・経年変化の姿は、AIで生成しない。実写かサイトの写真だけを使う
- 商品に紐づかない場面の素材は「季節の着こなし」フォルダに入れる

## BGM

- `assets` の中の、名前が `bgm_` で始まる曲(`.m4a`)を、名前の順に、投稿ごとに1曲ずつ使う
- 今は6曲(YouTubeオーディオ ライブラリ、帰属表示不要)。冒頭16秒、音量をそろえてある
- 企業のInstagramで使える権利の確認ができた曲だけを入れる
